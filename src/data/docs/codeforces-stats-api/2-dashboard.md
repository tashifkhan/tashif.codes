# Dashboard

`GET /` is a live profile explorer: rating, max rating, contest count, solved count, recent rating changes.

Live [playground](https://codeforces-stats.tashif.codes/playground) and [OpenAPI](https://codeforces-stats.tashif.codes/docs). Sample handle `tourist`. Schemas: [Envelope and schemas](3.1-envelope-and-schemas).

`/playground` tests the canonical username routes. Multi-handle and upcoming-contest helpers are easier from `/docs` (Swagger).
