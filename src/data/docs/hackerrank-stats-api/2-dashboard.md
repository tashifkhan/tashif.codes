# Dashboard

`GET /` loads a public HackerRank username into profile, heatmap, badges, recent submissions, and contest history.

Live [playground](https://hackerrank-stats.tashif.codes/playground) and [OpenAPI](https://hackerrank-stats.tashif.codes/docs). Schemas: [Envelope and schemas](3.1-envelope-and-schemas).

`/playground` is the canonical tester.
