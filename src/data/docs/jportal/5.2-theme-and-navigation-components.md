## Theme selector dialog

### Component architecture

```mermaid
flowchart TD
  Btn["header button"] --> Gestures["click hold swipe"]
  Gestures --> Store["useThemeStore"]
  Dialog["Dialog"] --> Toggle["ThemeToggle"]
  Dialog --> Grid["ThemeSelector"]
```

| Gesture | Action |
| --- | --- |
| Click under 500ms | Open dialog |
| Hold 500ms | Toggle light/dark |
| Swipe X or Y past 50px | Next or previous preset |

Refs: `holdTimeoutRef`, `isHoldingRef`, `touchStartRef`, `hasSwipedRef`.

### Event handler implementation

```mermaid
flowchart TD
  Down["pointer down"] --> Timer["500ms hold"]
  Timer --> Mode["toggleTheme"]
  Move["pointer move"] --> Swipe["changeToTheme"]
  Up["pointer up"] --> Open["open dialog unless hold or swipe"]
```

## CSS variables and theme tokens

### Variable mapping architecture

```mermaid
flowchart TD
  Root["--background"] --> Map["@theme inline --color-background"]
  Map --> Util["bg-background"]
```

Radius: `--radius-sm` = `calc(var(--radius) - 4px)` and siblings. Fonts: `--font-sans`, `--font-mono`, `--font-serif`.

Grade and marks tokens in `index.css` (`--color-grade-aa`, `--color-marks-outstanding`, …). Marks bands in `MarksCard` are 80/60/40, not 90/70/50.

## View transition animations

### Animation implementation

```mermaid
sequenceDiagram
  participant Btn as ThemeToggle
  participant CSS as --x --y
  participant VT as startViewTransition

  Btn->>CSS: set click coords
  Btn->>VT: apply .dark
  VT-->>Btn: expand / shrink clip-path 1s
```

`@supports (view-transition-name: none)`. Without it, the class flips with no animation.
