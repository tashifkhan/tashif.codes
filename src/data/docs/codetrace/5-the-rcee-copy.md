# The RCEE copy

Ramachandra College of Engineering shipped a placement tracker that is CodeTrace with the branding swapped. Same stacked coding-profile dashboard. Same idea of one page for GitHub plus the contest sites.

I am not guessing. Side-by-side screenshots, the Vercel URL, and what they changed live in the blog post:

**[Ramachandra College copied CodeTrace](/blog/Ramachandra-College-CodeTrace-Copy)**

Their tracker: [sptracker1.vercel.app](https://sptracker1.vercel.app/). College site: [rcee.ac.in](https://rcee.ac.in).

This page exists so the docs do not pretend the only consumer of these APIs is me. If you are a college building a placement portal, fork [stats-api-demo](https://github.com/tashifkhan/stats-api-demo), keep the license, and say where it came from. Copying the UI onto a Vercel URL without that is the thing I wrote the post about.
